# Research context

The project asks whether sector differences in S&P 500 returns during five 2025 tariff-policy windows operate directly or through firm-level financial characteristics. The intended paper structure from the research notes is: data/problem, generalized mediation methodology, results/conclusion, and a later-written introduction.

The analysis treats sector indicators as descriptive exposures rather than causal assignments. Financial-statement metrics are candidate mediators, and event-window stock returns are outcomes. The paper plans to report direct sector effects, selected mediator effects, and indirect effects, with formulas aligned to the referenced generalized mediation paper.

Two consistency issues were found during repository preparation:

1. The prose describes Utilities as the baseline sector, while an original R comment says Basic Materials. The original positional selection actually omitted Utilities; the working script now names Utilities explicitly as the baseline.
2. The original stage-1 instructions reverse the anchor dates. This repository uses 2025-01-01 through 2025-04-30 and records the correction.

The source PDFs and detailed draft prose remain in the private Google Drive research folder and are not copied into this code repository, avoiding accidental redistribution of papers or unpublished writing.
